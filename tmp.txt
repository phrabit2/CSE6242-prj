운영에서 할 일

1. 71번에서 현재 값 확인:

bash
grep -rn 'span.collected.uri.type' /app/pinpoint-agent-wcs/pinpoint-root.config /app/pinpoint-agent-wcs/profiles/release/pinpoint.config

AUTO이거나 아예 없으면 그게 원인이야. 어느 파일에 있는지도 확인 — 운영은 release 프로파일로 도니까(pinpoint.profiler.profiles.active=release), profiles/release/pinpoint.config에 있는 값이 실제 적용돼. root config만 고치면 profile 값에 덮여서 안 먹을 수 있어.

2. RAW로 변경 (실제 적용되는 release profile 파일을):

bash
sudo sed -i 's/^profiler.span.collected.uri.type=.*/profiler.span.collected.uri.type=RAW/' \
  /app/pinpoint-agent-wcs/profiles/release/pinpoint.config

# 확인
grep -n 'span.collected.uri.type' /app/pinpoint-agent-wcs/profiles/release/pinpoint.config

옵션이 주석 처리(#)돼 있거나 아예 없으면 sed가 안 먹으니, 그 경우 vi로 직접 추가하거나 append:

bash
echo 'profiler.span.collected.uri.type=RAW' | sudo tee -a /app/pinpoint-agent-wcs/profiles/release/pinpoint.config

(단 중복 라인이 생기면 마지막 값이 이기니, 기존 라인이 있으면 sed로 고치는 게 깔끔해)

3. ⚠️ 앱 재기동 필요 (운영) — config는 JVM 기동 시 읽히니 wcs 재시작해야 적용돼. prd라 협의 시점에:

bash
sudo systemctl restart wcs
